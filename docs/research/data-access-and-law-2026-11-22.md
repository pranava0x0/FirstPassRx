# FirstPassRx: how formulary / PA / price data is published, and the law behind it

As of 2026-11-22. "Verified live" = I fetched it myself today. "Unconfirmed" = not read in primary text this pass.

## 0. Biggest findings
1. **Marketplace (QHP) formularies are already public JSON, per plan, with PA / step therapy / quantity-limit booleans and RxNorm IDs.** CMS publishes a Machine-Readable PUF listing each issuer's `index.json`. Verified live: the PY2026 PUF at <https://data.healthcare.gov/datafile/py2026/machine_readable_PUF.xlsx> lists 108 issuer URLs. Moda, Elevance (`www22.elevancehealth.com/...Elevance-Health-Data-Index.json`) and a FormularyNavigator-hosted index returned 200 to curl. UHC's index returned 403 to curl (browser-only). A sample `drugs.json` row has `rxnorm_id`, `drug_tier`, `prior_authorization`, `step_therapy`, `quantity_limit`, `years`. Schema: <https://github.com/CMSgov/QHP-provider-formulary-APIs>.
2. **Medicare Part D formularies are monthly flat files from CMS** (pipe-delimited, free since Jan 2021; tier, PA, step therapy flags in the 2026 layout). <https://data.cms.gov/sites/default/files/2025-10/0564eb37-402d-4110-bd98-2d5399dc30e7/PUFRecordLayout-2026.pdf>. This replaces Humana PDP PDF scraping for the Part D side.
3. **No law currently forces Medicaid or commercial (non-QHP) payers to publish formularies in a machine-readable format.** 42 CFR 438.10(i)(3) says Medicaid MCO formularies must be posted in a "machine readable file and format as specified by the Secretary" (eCFR text read today), but I found no format the Secretary has specified. State PDLs stay PDF/HTML.
4. **The CMS interoperability rules (9115-F, 0057-F) mostly produce member-authenticated APIs**, not public feeds. Public formulary FHIR is optional under the Da Vinci IG. Few payers expose it without a client ID or payer ID (see section 8).
5. **CMS-0062-P (April 2026) would extend PA APIs and NCPDP formulary/PA standards to drugs from 2027-10-01, but is still a proposal.** I found no final rule.
6. **Transparency in Coverage prescription-drug MRF is still unimplemented**, and the Dec 2025 proposal (CMS-9882-P) does not change it.
7. **Price side:** NADAC (data.medicaid.gov, weekly, public-domain), RxNorm, DailyMed and openFDA are free APIs, verified live today. Cost Plus's price list API is open (verified live, GET works, HEAD returns 405). GoodRx blocks bots and its ToS text could not be read.

## 1. CMS Interoperability and Patient Access (CMS-9115-F)
- Final rule, 85 FR 25510 (2020-05-01), effective 2020-06-30. Patient Access and Provider Directory API compliance 2021-01-01, enforcement began 2021-07-01. [Fed. Reg. text](https://www.govinfo.gov/content/pkg/FR-2020-05-01/html/2020-05050.htm); [CMS FAQ on provider directory API](https://www.cms.gov/priorities/key-initiatives/burden-reduction/interoperability/faqs/provider-directory-api).
- Payers: MA organizations (42 CFR 422.119), Medicaid and CHIP FFS (431.60, 457.730), Medicaid and CHIP managed care, QHP issuers on FFEs (45 CFR 156.221). Managed-care cites (438.242(b)(5), 457.1233(d)): unconfirmed in text this pass.
- **Formulary content, confirmed in eCFR:** MA-PD Patient Access API must carry "formulary data that includes covered Part D drugs", including tier and utilization management ([42 CFR 422.119(b)(2)(ii)](https://www.ecfr.gov/current/title-42/section-422.119)). Medicaid FFS states must make "preferred drug list information" available as part of covered outpatient drug info, within one business day of its effective date ([42 CFR 431.60(b)(4)](https://www.ecfr.gov/current/title-42/section-431.60)).
- These APIs are for current members (OAuth-gated). The Provider Directory API must be public with no developer registration (CMS FAQ above). The formulary API does not carry the same public mandate; public use comes from the Da Vinci IG option (section 8).
- Standard: HL7 [Da Vinci PDex US Drug Formulary](https://www.hl7.org/fhir/us/davinci-drug-formulary/) v2.1.0 (STU2, FHIR R4). The IG allows an unauthenticated tier for formulary-only data and says servers must not log consumer identity. Endpoint discovery is out of scope of the IG. CMS notes IG v2.0.1 expired 2026-01-01 (secondary source, search summary).

## 2. CMS Interoperability and Prior Authorization (CMS-0057-F)
- Final 2024-01-17; [fact sheet](https://www.cms.gov/newsroom/fact-sheets/cms-interoperability-and-prior-authorization-final-rule-cms-0057-f); [Fed. Reg. 89 FR 8758, 2024-02-08](https://www.federalregister.gov/documents/2024/02/08/2024-00895/medicare-and-medicaid-programs-patient-protection-and-affordable-care-act-advancing-interoperability).
- Payers: MA orgs, Medicaid/CHIP FFS and managed care, QHP issuers on FFEs. QHPs are exempt from the 72h/7-day decision times.
- **Decision times:** 72 hours expedited, 7 calendar days standard (non-QHP). Operational provisions including denial reasons and Patient Access API metrics: 2026-01-01. First public PA metrics posting: 2026-03-31, then annually. APIs (Patient Access additions, Provider Access, Payer-to-Payer, Prior Authorization API): 2027-01-01 (varies by payer type; Medicaid managed care by rating period starting on/after that date). Fact sheet above.
- **Drugs are excluded.** The fact sheet says the PA additions to the Patient Access API exclude drugs, and the denial-reason requirement does not apply to drug decisions. eCFR 422.119(b)(1)(iv) also reads "excluding drugs". Confirmed.
- Prior Authorization API uses Da Vinci CRD/DTR/PAS (IG names: from CMS API/IG page, [link](https://www.cms.gov/priorities/key-initiatives/burden-reduction/implementation-guides-standards/application-programming-interfaces-apis-and-relevant-standards-and-implementation-guides-igs)); I did not read the IG list there line by line.
- **Drug PA proposal, CMS-0062-P:** released 2026-04-10, [91 FR 19890, 2026-04-14](https://www.federalregister.gov/documents/2026/04/14/2026-07205/medicare-and-medicaid-programs-patient-protection-and-affordable-care-act-interoperability-standards). [Fact sheet](https://www.cms.gov/newsroom/fact-sheets/2026-cms-interoperability-standards-prior-authorization-drugs-proposed-rule): drug PA decisions in 24 hours for Medicaid/CHIP, 72 hours standard / 24 hours expedited for FFE QHPs; NCPDP SCRIPT, Formulary & Benefit and Real-Time Prescription Benefit required from 2027-10-01; drug PA data in Patient Access, Provider Access, Payer-to-Payer APIs. Comment period reported closed 2026-06-15 (search summary). **Status: proposed, no final rule found.**
- **Industry pledge:** HHS/CMS announced 2025-06-23 a voluntary AHIP-led pledge covering MA, Medicaid MCOs, Marketplace and commercial plans: FHIR-based ePA, real-time responses by 2027, honor existing PAs across transitions. [HHS release](https://www.hhs.gov/press-room/kennedy-oz-cms-secure-healthcare-industry-pledge-to-fix-prior-authorization-system.html). Voluntary, not a rule; one-year reviews report uneven follow-through ([KFF Health News via search](https://kffhealthnews.org/?p=2261522)); drug-specific commitments not found.

## 3. ACA / QHP
- [45 CFR 156.122(d)](https://www.ecfr.gov/current/title-45/section-156.122) (eCFR read today): (d)(1) plans must publish an up-to-date, accurate, complete list of covered drugs with tiering and restrictions, viewable on the public website without an account or policy number; (d)(2) FFE QHPs post in an HHS-specified format and submit to HHS. The word "machine-readable" does not appear; the JSON requirement comes via (d)(2) and CMS guidance. (c): exceptions decided in 72 hours standard / 24 hours expedited.
- JSON schema and index files: [CMSgov/QHP-provider-formulary-APIs README](https://github.com/CMSgov/QHP-provider-formulary-APIs) (read today): must be public over HTTP(S), `plans.json` / `drugs.json` / `providers.json` / `index.json`. Monthly update requirement per CMS MR-PUF page ([catalog](https://catalog.data.gov/dataset/machine-readable-puf-py2026)). CMS does not QA the URLs.
- Caveat: the tier vocabulary is free text per issuer (e.g. `ACA-PREVENTIVE-DRUGS`), so tier normalization is still needed.

## 4. Medicare Part D
- [42 CFR 423.128](https://www.ecfr.gov/current/title-42/section-423.128): website must show a current formulary, updated at least monthly ((d)(2)(ii)); negative-change notice per 423.120(f); real-time tool must show formulary alternatives and UM status ((d)(4)).
- CMS monthly PUF: 8 pipe-delimited files, built from the first Plan Finder posting each month; quarterly adds pricing. Excludes non-Part D plans, PACE, employer, demonstration plans. [Order page](https://www.cms.gov/research-statistics-data-and-systems/files-for-order/nonidentifiabledatafiles/prescriptiondrugplanformularypharmacynetworkandpricinginformationfiles); [2026 layout](https://data.cms.gov/sites/default/files/2025-10/0564eb37-402d-4110-bd98-2d5399dc30e7/PUFRecordLayout-2026.pdf); [2027 methodology](https://data.cms.gov/sites/default/files/2026-10/Methodology-PUF-2027.pdf).
- Utilization data: [Part D Prescribers by Geography and Drug](https://catalog.data.gov/dataset/medicare-part-d-prescribers-by-geography-and-drug) is yearly, per-year dataset IDs under `data.cms.gov/data-api/v1/dataset/<id>/data`. API filter syntax: unconfirmed.

## 5. Medicaid
- [42 CFR 438.10(i)](https://www.ecfr.gov/current/title-42/section-438.10) (read today): MCO/PIHP/PAHP must make formulary info available (electronic or paper): covered drugs, tier, and a drug list posted on the website as a "machine readable file and format as specified by the Secretary". No update frequency stated. No specified format found.
- [SSA 1927(d)](https://www.ssa.gov/OP_Home/ssact/title19/1927.htm) / 42 USC 1396r-8(d)(5): PA programs must respond within 24 hours and allow a 72-hour emergency supply. Subsection mapping from state agency sources (e.g. [MS Medicaid](https://medicaid.ms.gov/wp-content/uploads/2024/07/72-hour-emergency-prescription-7_2024.pdf), [LA MCO manual](https://ldh.la.gov/assets/medicaid/MCPP/5.23.23/2023-LDH-6_MCO_Manual_Pharmacy_PA_2023-05-23.pdf)); statute text itself not read: unconfirmed. P&T committee requirements in (d)(4): text not read here: unconfirmed. State P&T meetings are public (examples: [PA DHS](https://www.pa.gov/agencies/dhs/about/councils-committees/pharmacy-committee), [WA HCA](https://www.hca.wa.gov/node/2876)).
- Data: NADAC weekly, [medicaid.gov pricing page](https://www.medicaid.gov/medicaid/prescription-drugs/pharmacy-pricing). Verified live: `https://data.medicaid.gov/api/1/datastore/query/fbb83258-11c7-47f5-8b18-5f8e79f7e704/0?limit=1` (NADAC 2026) returns JSON with NDC, `nadac_per_unit`, `effective_date`. State Drug Utilization Data 2025 ID `158a1baa-5506-400a-8ec3-97756f0b0536` (from the metastore, same API pattern).

## 6. Transparency in Coverage (TiC)
- 2020 final rule (85 FR 72158; 45 CFR 147.210/147.212, 26 CFR 54.9815-2715A3, 29 CFR 2590.715-2715A3: citations from memory, unconfirmed) requires in-network rate, allowed-amount and prescription drug MRFs.
- **Prescription drug MRF: not implemented.** Enforcement deferred; Health Affairs (2026-03) says the Departments "have not yet implemented" it ([link](https://www.healthaffairs.org/doi/full/10.1377/forefront.20260313.708647)).
- Proposed update CMS-9882-P: [Fed. Reg. doc 2025-23693, 2025-12-23](https://www.govinfo.gov/content/pkg/FR-2025-12-23/html/2025-23693.htm), [CMS fact sheet](https://www.cms.gov/newsroom/fact-sheets/transparency-coverage-proposed-rule-cms-9882-p); comments closed ~2026-02-23. Does not substantively change the Rx file, which the Departments say they will address separately. Final-rule status: unconfirmed (none found).
- Takeaway: TiC gives medical negotiated rates, not drug formulary or PA data.

## 7. State laws (representative)
- **Step therapy:** ABA Health eSource (2026) counts 38 states + DC with some step therapy regulation; Illinois bans step therapy in fully insured plans from 2026-01-01; NJ effective 2026-01-01; Alaska 2027-01-01. [ABA](https://www.americanbar.org/groups/health_law/resources/esource/2026/state-step-therapy-laws-erisa/). Exact count unverified against a tracker. Applies to fully insured plans, not ERISA self-funded.
- **Gold-carding:** Texas HB 3459 (87th Leg., 2021) exempts physicians with 90% approval over 6 months; HB 3812 (89th Leg., 2025) updates it. [TDI](https://tdi.texas.gov/health/hb3459.html). Insurance Code section number (4201.655): unconfirmed.
- **Formulary change notice:** Illinois 215 ILCS 134/25 (60 days' notice before mid-year drug removal; [ILGA](https://ilga.gov/ftp/ILCS/Ch%200215/Act%200134/021501340K25.html)); Maine 60 days ([Public Law ch. 429](https://www.legislature.maine.gov/legis/bills/bills_128th/chapters/PUBLIC429.asp)); Kentucky 30-60 days by regulation ([KAR](https://apps.legislature.ky.gov/law/kar/downloads/docs/7641/document.engrossed.pdf)); Minnesota 62Q.83. I saw excerpts only.
- **ePA / NCPDP SCRIPT:** Maryland (payers needed a compliant online process by 2026-07-01; [MHCC](https://mhcc.maryland.gov/electronic-preauthorization)); Minnesota 62J.497 mandates NCPDP SCRIPT for prescriptions ([statute](https://www.revisor.mn.gov/statutes/cite/62J.497/pdf)); West Virginia 2023 bill; Alaska 2025. Federal baseline: ONC certification moves to newer SCRIPT by 2028-01-01 (search summary). AMA keeps a [state PA law chart](https://www.ama-assn.org/system/files/prior-authorization-state-law-chart.pdf).
- None of these create a public data feed; they change the rules the PA data must reflect.

## 8. Public FHIR formulary endpoints (the "replace PDF scraping" question)
- Confirmed anonymous-capable by IG design, but no payer endpoint list exists. [Da Vinci IG](https://www.hl7.org/fhir/us/davinci-drug-formulary/specification.html).
- Optum/Change Healthcare formulary API: anonymous path, requires a "CHC Payer ID" parameter ([Optum](https://developer.optum.com/dataaccessandinteroperability/reference/interoperability-patient-access-api-formulary-v1-overview)). I could not read the page body today.
- BCBS South Carolina formulary API: public, non-member-specific, but needs an onboarded client ID header ([link](https://www.southcarolinablues.com/web/public/brands/interdev/developers-alt/formulary-api)). Not registration-free.
- Clever Care Health Plan: public rate-limited formulary resources per a third-party listing ([apis.io](https://apis.io/apis/clevercarehealthplan/clevercarehealthplan-drug-formulary-api/)). Unconfirmed against the plan's own site.
- Humana, Aetna, Cigna, Centene, Elevance, UHC FHIR formulary endpoints: **unconfirmed**; I found no unauthenticated endpoint. A probe of each portal is a worthwhile next step.
- Vendors such as 1up host formulary FHIR for plans ([1up](https://1up.health/products/formulary/)).

## 9. Free drug and price APIs (verified live today)
- RxNav/RxNorm: no license needed except `getProprietaryInformation`; limit 20 req/s per IP; attribution required. [ToS](https://lhncbc.nlm.nih.gov/RxNav/TermsofService.html). `https://rxnav.nlm.nih.gov/REST/rxcui.json?name=lisinopril` returned an RxCUI.
- DailyMed v2 REST (`dailymed.nlm.nih.gov/dailymed/services/v2/spls.json`): GET only, JSON/XML, no key; bulk SPL downloads. [docs](https://dailymed.nlm.nih.gov/dailymed/app-support-web-services.cfm).
- openFDA (`api.fda.gov/drug/ndc.json`): data use "generally unrestricted", service under [ToS](https://open.fda.gov/terms/). NDC Directory bulk terms: unconfirmed.
- Cost Plus: `GET https://api.costplusdrugs.com/pricelist/cpd` returns JSON (verified). `costplusdrugs.com/robots.txt` allows `/` for all agents. No API terms found. ToS page returns 403 to curl: unconfirmed.
- GoodRx: `robots.txt` disallows only a few paths (`/static`, `/ajax`, price-alert etc.; read today). ToS page 403s to automated fetch: unconfirmed whether it prohibits scraping. GoodRx's [developer usage guide](https://www.goodrx.com/developer/usage-guide) (search summary) says its API is for real-time user-driven requests and storing API data is contractually prohibited. Treat GoodRx as link-out only unless the ToS is read and permits more. Not legal advice.

## 10. Copyright / database rights
- [Feist v. Rural, 499 U.S. 340 (1991)](https://www.govinfo.gov/content/pkg/USREPORTS-499/pdf/USREPORTS-499-340.pdf): facts are not copyrightable; a compilation is protected only for original selection/arrangement, and that protection excludes the facts. A list of which drugs a plan covers and at what tier is a factual list. I found no case on formularies specifically: unconfirmed. The U.S. has no sui generis database right.
- Practical limits are contract/ToS (GoodRx), bot blocks (CFAA is not engaged by public pages, but ToS breach and blocking still matter), and attribution rules (RxNorm). State and federal government works (PDLs, CMS files) are public; federal works have no copyright (17 USC 105).
