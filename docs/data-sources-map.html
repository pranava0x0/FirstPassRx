Where formulary data lives, and the rules that make it public

Each card is one kind of source FirstPassRx reads or could read. The left column lists the federal rules, case law and state laws behind them. Hover a source to light up the rules that require it. Built 2026-11-22 from docs/research/sources-graph.json (researched 2026-11-22, cited in docs/research/data-access-and-law-2026-11-22.md) and src/data/formulary.json.

How a coverage cell is built today

  1. Find the documentPayer roster per state, state PDL firstdocs/research/states-roster-*.json
  2. Archive the bytessha256 + fetch tier per hostnpm run archive-sources
  3. Extract rowsLayouts: optum, mgb, bcbs, mhdl, pdlcols, tieredscripts/source_rows.py
  4. Gather and checkHaiku reads one document for every class; Sonnet checks.claude/workflows/formulary-gather.js
  5. Merge and auditEvery claim against its source rowmerge-gather.mjs · audit-cells.mjs
  6. Price and sigCost Plus API, GoodRx in Chrome, label tablecostplus.mjs · apply-label-sigs.mjs
